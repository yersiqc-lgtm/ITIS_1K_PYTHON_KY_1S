# report.md

Я запускал программы и смотрел traceback. В bug_3 traceback не было, поэтому там смотрел значения и менял код по шагам.

## bug_1.py

Функция `to_grade`: для 71 стояло `score > 71`, поэтому 71 попадало не в "хорошо". Поменял на `>= 71`.

Функция `count_grades`: словарь сначала пустой, а код сразу делал `counts[grade] += 1`. Получался `KeyError`. Исправил через `counts.get(grade, 0) + 1`.

Функция `main`: после `split()` получались строки. Из-за этого сравнение с числами и `sum()` не работали. Сделал преобразование через `int`.

## bug_2.py

`find_index`: `return -1` был внутри цикла. Из-за этого функция проверяла только первый товар. Вынес `return -1` после цикла.

`remove_all`: создавался список `result`, но возвращался `results`. Это `NameError`. Исправил имя.

`get_last`: срез начинался на один элемент раньше, потому что было `- n - 1`. Поменял на `items[-n:]`.

В `main` число `len(shopping)` складывалось со строками. Был `TypeError`. Добавил `str()`.

## bug_3.py

`count_above`: было `count =+ 1`. Это не увеличение счетчика, а присваивание +1. Поэтому ответ почти всегда был 1. Поменял на `count += 1`.

`max_streak`: если самая длинная серия была в самом конце списка, она не записывалась в `best`. Добавил проверку после цикла.

`average`: использовалось `//`, то есть целочисленное деление. Из-за этого терялась дробная часть. Поменял на `/`.

## bug_4.py

Тут я писал assert на случаи, которых нет в примерах.

`merge_sorted`: после цикла добавлялся остаток только списка `a`. Если элементы оставались в `b`, они пропадали. Добавил `result += b[j:]`.

`is_sorted`: `return True` стоял внутри цикла. Из-за этого после первой правильной пары функция уже заканчивалась. Еще пустой список и список из одного элемента возвращали `None`. Вынес `return True` после цикла.

`dedupe`: параметр `seen=[]` сохранялся между вызовами функции. Поэтому второй вызов мог дать неправильный результат. Сделал `seen=None`, а новый список создаю внутри функции.

`median`: для списка с четным количеством элементов функция брала только правый средний элемент. Сделал среднее двух центральных. Для пустого списка добавил `ValueError`.

Примеры assert, которыми я проверял:
```python
assert merge_sorted([], [1, 2]) == [1, 2]
assert is_sorted([]) is True
assert is_sorted([1, 2, 0]) is False
assert dedupe([1, 1, 2]) == [1, 2]
assert dedupe([1, 2]) == [1, 2]
assert median([1, 2]) == 1.5
```
